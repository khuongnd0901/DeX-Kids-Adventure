
# BRD - DeX Kids Adventure

Audience: children aged 2–6 riding as car passengers; parent controls the session.
Vision: turn real journeys into age-appropriate explorations of the world with capybara tour guide and automatic 2D scenery.
Child interaction: passive. No tapping required while driving.
Parent: start, pause, stop, screen-time limits, audio-only and quiet mode from phone.
Default privacy: offline, no ads, no default cloud GPS/voice collection.
Out of scope: driver navigation, YouTube player, unverified AI narration, reverse engineering other apps' routes.
Success measured through source verification, correct curated POIs, device animation smoothness and child-safe audio priority.


# SRS - Initial requirement baseline

R-001 Continuous full-HD-friendly 16:9 libGDX scenery at targeted stable 30 FPS.
R-002 Deterministic procedural chunks without per-trip hand-crafted maps.
R-003 Motion smoothly reacts to GPS with outlier/loss detection; supports GPX replay.
R-004 Offline OSM POI lookups use confidence and distinct NEAR/APPROACHING/PASSING/VISITED events.
R-005 Facts have source URLs and verification dates; absent reliable evidence narrate general topics only.
R-006 Vietnamese audio from reviewed clips/offline-capable TTS, subtitles and talking animation.
R-007 Child DeX display is passive; parent phone controls session.
R-008 Explicit authenticated IPC with existing DeX-Assistant, introduced only after audit.
R-009 GPS/history local retention and deletion; no tracking/ads; navigation audio prioritized.
R-010 Device-specific 60-min perf, memory, thermal and reliability evidence before release.

Each requirement is a target, not an achieved feature. Implementation status tracked in .agent/TASKS.md.

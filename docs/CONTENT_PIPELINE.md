
# Content pipeline

1. Download appropriately licensed OSM extracts for specific region (not entire uncompressed nation).
2. Normalize POIs with stable IDs, coordinates, categories, geometry and source/license.
3. Editorially verify each named fact and write language suitable for children aged 2–6.
4. Record source and lastVerifiedAt; publish signed/versioned offline content packs.
5. Prepare prerecorded Vietnamese narration and subtitles; test audio focus.
6. If a location is unreliable or unverified, fall back to generic exploration prompts.

AI-generated text is a draft only; never narrate unreviewed output to children.

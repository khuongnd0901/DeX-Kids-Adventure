# T-016 — AI Kids Conversation · Direct Gemini/Groq + Offline Quiz Cache

**State: IN_PROGRESS (2026-10-10).** Issue [#19](https://github.com/khuongnd0901/DeX-Kids-Adventure/issues/19). Main-only development; no backend.

## Product behaviour
- Existing **real GPS → sourced OSM POI engine** remains the only authority for which location *might be nearby*. No AI access to live coordinates, heading, routing, child history or navigation. All source-audited candidate POIs retain the existing "GPS gần địa danh · ước tính" disclaimer; this is *not* road/entrance mapping. `assets/poi/reviewed.tsv` remains empty.
- Parent dashboard has **AI Kids OFF by default**. Independently configure Gemini and/or Groq API keys, model ID, provider enabled, default provider and parental assertion of Free Tier eligibility in a native same-DeX-display UI. API key is entered only on device, encrypted via AES-GCM AndroidKeyStore, not committed to repository or shown after saving. If parent enables multiple eligible providers, retry 429 / server / timeout with only those eligible providers. There is NO assumption models are free or that account limits have been verified.
- **Prepare quiz cache** button runs background REST queries for up to 13 source-audited offline POIs, aiming for 10–12 distinct Vietnamese quiz questions per POI and age. Each AI response contains only a question, follow-up and a numerical `factIndex` into an explicit list of known sourced fact sentences/approved original answer: **the actual answer is always selected locally, not accepted from provider**. Invalid count (10–20), wrong index, duplicate, unsafe or too long content fails closed. Draft questions from a model are marked **AI · THAM KHẢO** and need adult review; matching an answer index cannot prove all generated questions are factually correct.
- Cache is private to the app: versioned, SHA-256 invalidation when trusted narrative/answer changes, per-age isolation, 14-day expiry and bounded entries. It stores ONLY question wording, known fact answer and safe follow-up, never personal speech, GPS or API keys. Cached questions run even without Internet; no cached pack, no AI or quota error -> existing original offline question. A single live POI may opportunistically prefetch for a later trip without blocking UI.
- If on-device Vietnamese ASR recognizes a short answer and **a SECOND, explicitly confirmed "Cho phép AI phản hồi từ lời bé" consent** is enabled, a maximum 110-character short text snippet may go to the selected cloud API over TLS to generate a brief answer and next question. Reject any numbers, names, home/school/address/telephone or similar signs of personal information before network; imperfect filtering is openly disclosed. No PCM/audio, GPS coordinates, child identity or persisted chat history is sent or stored. Parent can disable at any time; late results are dropped on parent menu/activity end or consent revocation. **Cloud child text consent defaults OFF and is independent of microphone permission and AI quiz generation consent.**
- **Fail-safe:** No ready provider, network, key, model, consent or output validation -> existing deterministic T-015 on-device answer interpreter and script. No cloud STT or offline ASR downgrade; no Quiet Mode; no app actions/tools generated by AI; the system does not send commands to DeX Assistant.
- Bounded HTTPS calls (5s connect, 12s read, 32 KiB response, 8 KiB prompt, 20 per active gateway instance); never run on the UI/GL thread. Only Gemini REST `generateContent` and Groq `chat/completions`, modeled after DeX-Assistant-Ui `DirectAiChat` and `AiCredentialStore`. No user-provided endpoint or insecure HTTP. Exact provider-model eligibility is account-dependent; no auto-fetch model list as price or free proof.

## Parent setup
1. On the external DeX monitor open Parent dashboard → **Cấu hình Gemini / Groq · model · API key**. Select provider, set its concrete model ID, paste API key, enable, optionally set preferred and confirm you independently verified Free Tier/quota.
2. Turn on **AI Kids** separately. Optionally press **Tạo cache 10–12 câu đố / địa danh** while on Wi-Fi, before a drive. Runtime uses cached packs first.
3. For **actual spoken conversation**, turn on **Bật giọng kể offline tiếng Việt** and grant on-device microphone permissions via **Cho phép nghe câu trả lời của bé (offline)** (T-015). This alone **does NOT send speech text to any provider**.
4. Only if explicitly desired, read the warning and separately enable **Cho phép AI phản hồi từ lời bé**. Then short non-sensitive recognized text may be sent to the selected provider. The provider’s own processing/retention and account eligibility must be reviewed before using with children. Disabling consent leaves local offline response working. Child is a passenger; no interaction from the driver.

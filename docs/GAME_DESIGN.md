
# Game design - child-facing vision

The Capybara Explorer rides a yellow bus. Environments use pastel colors, rounded geometry, parallax, and positive/non-threatening animations.

Progression: open landscape -> city -> river/bridge -> parks -> airport, selected from trustworthy location context in future releases.
Audio policy: conversational Vietnamese, short age-appropriate explanations, pause/cooldown, no continuous interruptions.
Child display: no menus or debug overlays in production; the early developer demo explicitly shows simulated state.
Animation assets must contain separate frames/layers; final release may not consist of primitive boxes alone.

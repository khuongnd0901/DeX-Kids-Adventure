## Reproduced defects and changes

1. Parent reported first introduction had only subtitles. Before fix all three
   real sessions showed `voiceUnavailable=1`: TTS was lazily initialized at the
   first speak call, while its Android initialization is asynchronous. Warm the
   existing offline narrator when the journey initializes, with parent voice
   approval; no network voice fallback. Regression now requires zero silent
   fallback across three completed beats for each audience. Parent explicitly
   confirmed after installation: first introduction now has speech.
2. Gemini without a response schema sometimes returned a top-level array,
   despite the prompt requiring `{questions:[...]}`. Gateway rejected it.
   Add `generationConfig.responseJsonSchema` for quiz generation, requiring
   the root object, 10–12 rows and valid fact-index enum; preserve all existing
   local safety/source-answer validation. Reference:
   https://ai.google.dev/api/generate-content (GenerationConfig).
3. Old audio runner no longer compiled after T-024 added a fourth interrupted
   callback. Updated the test invocation only. Initial new audience harness
   accessed null subtitle text before first event; fixed guard. Picker first
   lacked interactive-window retrieval; enable it only on UiAutomation.
   A picker run was interrupted by an overlapping instrumentation launch;
   sequential rerun PASS. Retain earlier failures in local logs.
